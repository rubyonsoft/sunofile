# Suno 계정 전체 음악 백업

Suno에 만들어 둔 **본인 음악을 컴퓨터에 한꺼번에 보관하는 Windows용 프로그램**입니다.

컴퓨터 명령어를 몰라도 사용할 수 있도록 만들어졌습니다. 아래의 **초보자용 설치 방법**을 위에서부터 순서대로 따라 하세요. PowerShell이나 명령 프롬프트를 사용할 필요가 없습니다.

이 프로그램으로 다음 파일을 받을 수 있습니다.

- WAV 음악 파일
- MP3 음악 파일
- 가사
- 음악을 만들 때 사용한 프롬프트와 스타일
- 곡 정보가 담긴 JSON 파일
- MP3만, WAV만 또는 두 형식 모두 다운로드하도록 선택

같은 곡이 여러 Workspace에 들어 있어도 한 번만 저장합니다. 다운로드 도중 컴퓨터를 끄거나 오류가 발생해도 프로그램을 다시 실행하면 이미 받은 정상 파일은 건너뛰고 이어서 받습니다.

> 이 프로젝트는 Suno의 공식 프로그램이 아닙니다. 본인이 만들었거나 다운로드할 권한이 있는 곡에만 사용하고 Suno의 이용 약관과 정책을 지켜 주세요.

## 가장 간단한 사용 순서

처음 사용하는 분은 다음 순서만 기억하면 됩니다.

1. Google Chrome을 설치합니다.
2. Node.js를 설치합니다.
3. 이 프로그램을 ZIP 파일로 받습니다.
4. ZIP 파일의 압축을 풉니다.
5. `Suno_전체_백업_실행.cmd`를 두 번 클릭합니다.
6. 자동으로 만들어진 `config.json`에 본인의 Suno Workspace 주소를 넣습니다.
7. `Suno_로그인_준비.cmd`를 두 번 클릭하고 Suno에 로그인합니다.
8. `Suno_전체_백업_실행.cmd`를 다시 두 번 클릭합니다.
9. 숫자 `1`, `2`, `3` 중 하나를 눌러 MP3, WAV 또는 두 형식 모두를 선택합니다.
10. 프로그램 폴더 안의 `downloads` 폴더에서 결과를 확인합니다.

각 단계는 아래에서 그림 없이도 따라 할 수 있도록 자세히 설명합니다.

---

## 1단계: 준비물 확인

다음 항목이 필요합니다.

- Windows 10 또는 Windows 11 컴퓨터
- 인터넷 연결
- Google Chrome
- Node.js 20 이상
- 본인의 Suno 계정
- WAV 파일이 필요하다면 WAV 다운로드가 가능한 Suno 구독

### Google Chrome 설치하기

Chrome이 이미 설치되어 있다면 이 부분은 건너뛰세요.

1. 인터넷 브라우저에서 [Google Chrome 다운로드 페이지](https://www.google.com/chrome/)를 엽니다.
2. **Chrome 다운로드** 버튼을 누릅니다.
3. 받은 설치 파일을 두 번 클릭합니다.
4. Windows가 허용 여부를 물으면 내용을 확인한 뒤 **예**를 누릅니다.
5. 설치가 끝날 때까지 기다립니다.

### Node.js 설치하기

Node.js는 이 프로그램을 실행하는 데 필요한 무료 실행 도구입니다. 어려운 개발 프로그램을 직접 다룰 필요는 없습니다. 한 번만 설치하면 됩니다.

1. [Node.js 공식 다운로드 페이지](https://nodejs.org/)를 엽니다.
2. 화면에서 **LTS**라고 표시된 버전을 선택합니다.
3. Windows용 설치 파일을 받습니다. 보통 파일 이름 끝이 `.msi`입니다.
4. 다운로드한 설치 파일을 두 번 클릭합니다.
5. 설치 화면에서 **Next**를 누릅니다.
6. 이용 약관 동의 항목을 체크하고 **Next**를 누릅니다.
7. 설치 위치와 옵션은 잘 모르면 바꾸지 말고 계속 **Next**를 누릅니다.
8. **Install**을 누릅니다.
9. Windows가 허용 여부를 물으면 **예**를 누릅니다.
10. 설치가 끝나면 **Finish**를 누릅니다.

설치 후에는 열려 있던 프로그램 폴더 창을 닫았다가 다시 여는 것이 좋습니다. 프로그램 실행 시 `Node.js를 설치하세요`라는 메시지가 계속 나오면 Windows를 한 번 재부팅하세요.

## 2단계: 프로그램 다운로드하기

Git이나 PowerShell을 사용하지 않는 가장 쉬운 방법입니다.

1. [sunofile GitHub 페이지](https://github.com/rubyonsoft/sunofile)를 엽니다.
2. 파일 목록 위쪽의 초록색 **Code** 버튼을 누릅니다.
3. 나타난 메뉴에서 **Download ZIP**을 누릅니다.
4. 다운로드가 끝나면 Windows의 **다운로드** 폴더를 엽니다.
5. 받은 `sunofile-main.zip` 파일을 마우스 오른쪽 버튼으로 누릅니다.
6. **압축 풀기**, **모두 압축 풀기** 또는 비슷한 메뉴를 선택합니다.
7. 원하는 위치를 선택하고 **압축 풀기**를 누릅니다.

바탕 화면이나 문서 폴더처럼 찾기 쉬운 곳에 압축을 푸는 것을 권장합니다.

> ZIP 파일 안에서 프로그램을 바로 실행하면 안 됩니다. 반드시 먼저 **모두 압축 풀기**를 해야 합니다.

압축을 풀면 `sunofile-main`이라는 폴더가 생깁니다. 앞으로 설명하는 **프로그램 폴더**는 이 폴더를 뜻합니다.

---

## 3단계: 처음 한 번 실행해서 설정 파일 만들기

1. 압축을 푼 `sunofile-main` 폴더를 엽니다.
2. `Suno_전체_백업_실행.cmd` 파일을 찾습니다.
3. 해당 파일을 두 번 클릭합니다.
4. 검은색 창이 열리면 내용을 읽고 기다립니다.

처음 실행하면 다음 작업이 자동으로 진행됩니다.

- Node.js가 설치되어 있는지 확인합니다.
- `config.example.json`을 복사하여 `config.json`을 만듭니다.
- Workspace 주소를 입력하라는 메시지를 표시합니다.

검은색 창에 `config.json was created` 또는 `YOUR_WORKSPACE_ID`를 바꾸라는 내용이 나타나면 정상입니다. 아무 키나 눌러 창을 닫은 뒤 다음 단계로 이동하세요.

### Windows에서 실행 경고가 나타나는 경우

Windows가 `.cmd` 파일 실행 여부를 물을 수 있습니다. 반드시 이 GitHub 저장소에서 직접 받은 파일인지 확인하세요. 출처를 확인했다면 경고 창의 **추가 정보**에서 파일 이름을 확인한 후 실행 여부를 결정할 수 있습니다.

백신 프로그램이 파일을 차단한다면 무조건 끄지 말고, 먼저 GitHub의 소스 코드와 차단된 파일 이름을 확인하세요.

---

## 4단계: 본인의 Suno Workspace 주소 찾기

Workspace 주소에는 계정마다 다른 ID가 들어 있습니다. 이 주소 하나를 시작점으로 사용하여 계정의 활성 Workspace와 보관된 Workspace를 찾습니다.

1. Google Chrome에서 [Suno](https://suno.com/)를 엽니다.
2. 본인의 Suno 계정으로 로그인합니다.
3. 곡을 만들 때 사용하는 Workspace 하나를 엽니다.
4. 주소가 `https://suno.com/create?wid=...` 모양인지 확인합니다.
5. Chrome 화면 맨 위의 주소창을 한 번 클릭합니다.
6. 키보드의 `Ctrl` 키를 누른 상태에서 `C` 키를 눌러 주소를 복사합니다.

주소는 다음과 비슷한 모양입니다.

```text
https://suno.com/create?wid=xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx
```

`xxxxxxxx` 부분은 사람마다 다릅니다. 다른 사람의 Workspace 주소가 아니라 반드시 **본인 계정에서 연 Workspace 주소**를 사용하세요.

---

## 5단계: config.json에 Workspace 주소 넣기

1. 다시 `sunofile-main` 프로그램 폴더를 엽니다.
2. `config.json` 파일을 찾습니다.
3. `config.json`을 마우스 오른쪽 버튼으로 누릅니다.
4. **연결 프로그램** 또는 **다른 앱 선택**을 누릅니다.
5. **메모장**을 선택합니다.
6. 다음 줄을 찾습니다.

```text
"workspaceDiscoveryUrl": "https://suno.com/create?wid=YOUR_WORKSPACE_ID",
```

7. 큰따옴표 안의 `https://suno.com/create?wid=YOUR_WORKSPACE_ID` 부분만 지웁니다.
8. 키보드의 `Ctrl` 키를 누른 상태에서 `V` 키를 눌러 앞 단계에서 복사한 본인 Workspace 주소를 붙여 넣습니다.
9. 아래처럼 큰따옴표와 줄 끝의 쉼표가 그대로 남아 있는지 확인합니다.

```text
"workspaceDiscoveryUrl": "https://suno.com/create?wid=본인의-Workspace-ID",
```

10. 메모장 위쪽의 **파일 → 저장**을 누르거나 `Ctrl` 키를 누른 상태에서 `S` 키를 누릅니다.
11. 메모장을 닫습니다.

큰따옴표(`"`)나 줄 끝의 쉼표(`,`)를 지우면 설정 파일 오류가 날 수 있습니다. 잘못 수정했다면 `config.json`을 삭제하고 `Suno_전체_백업_실행.cmd`를 다시 실행하면 기본 설정 파일을 새로 만들 수 있습니다.

### config.json이 보이지 않는 경우

3단계에서 `Suno_전체_백업_실행.cmd`를 먼저 한 번 실행했는지 확인하세요. 그래도 없다면 `config.example.json` 파일을 복사해서 같은 폴더에 붙여 넣은 후, 복사한 파일 이름을 `config.json`으로 바꿔도 됩니다.

## 6단계: Suno 로그인 준비하기

Google은 자동화 전용 브라우저에서 로그인을 차단할 수 있습니다. 그래서 로그인할 때만 일반 Chrome 창을 사용합니다.

1. 프로그램 폴더의 `Suno_로그인_준비.cmd`를 두 번 클릭합니다.
2. 검은색 안내 창과 별도의 Chrome 창이 열립니다.
3. 열린 Chrome 창에서 본인의 Suno 계정으로 로그인합니다.
4. Suno의 Library 또는 곡 목록이 정상적으로 보이는지 확인합니다.
5. 방금 열린 **전용 Chrome 창을 완전히 닫습니다**.
6. Chrome 창이 닫히면 검은색 창에 로그인 준비가 끝났다는 메시지가 나타납니다.

전용 로그인 정보는 프로그램 폴더의 `.browser-profile`에 저장됩니다. 평소 사용하는 Chrome 프로필에는 영향을 주지 않습니다.

> `.browser-profile` 폴더에는 로그인 상태가 들어 있을 수 있습니다. 다른 사람에게 보내거나 인터넷에 올리지 마세요.

### `브라우저 또는 앱이 안전하지 않을 수 있습니다`라고 나오는 경우

자동으로 열린 백업 화면에서 Google 로그인을 시도하지 마세요. 모든 백업용 Chrome 창을 닫은 뒤 `Suno_로그인_준비.cmd`를 다시 실행하고, 그 프로그램이 연 일반 Chrome 창에서 로그인하세요.

## 7단계: 전체 백업 시작하기

1. 프로그램 폴더의 `Suno_전체_백업_실행.cmd`를 두 번 클릭합니다.
2. 검은색 창이 열립니다.
3. 처음에는 필요한 프로그램을 자동 설치하므로 `Installing required packages`라고 표시될 수 있습니다. 인터넷 속도에 따라 몇 분 걸릴 수 있으니 창을 닫지 마세요.
4. 다음과 같은 다운로드 형식 선택 메뉴가 나타납니다.

```text
Select the audio format to download:
  [1] MP3 only
  [2] WAV only
  [3] MP3 + WAV

Enter 1, 2, or 3:
```

5. 원하는 항목의 숫자를 키보드에서 한 번 누릅니다. `Enter` 키는 누르지 않아도 됩니다.

   - `1`: MP3 파일만 다운로드
   - `2`: WAV 파일만 다운로드
   - `3`: MP3와 WAV 파일을 모두 다운로드

6. 전용 Chrome 창이 열리면 마우스나 키보드를 사용하지 말고 기다립니다.
7. 프로그램이 Workspace와 곡 목록을 찾고 곡을 순서대로 저장합니다.

어떤 오디오 형식을 선택해도 가사, 프롬프트와 메타데이터는 함께 저장됩니다. 나중에 다른 형식을 선택해서 다시 실행하면 기존 파일은 유지하고 새로 선택한 형식 중 빠진 파일만 추가로 받습니다.

`Suno_WAV_백업_실행.cmd`를 실행하면 선택 메뉴 없이 WAV만 다운로드합니다. 보통은 세 가지 중에서 고를 수 있는 `Suno_전체_백업_실행.cmd`를 사용하세요.

곡마다 다음과 비슷한 메시지가 나타납니다.

```text
[3] 녹턴 Op. 2 No. 1
  가사 저장 완료
  프롬프트/스타일 저장 완료
  메타데이터 저장 완료
  MP3 다운로드 완료
  WAV 다운로드 완료
```

곡이 많으면 몇 시간 이상 걸릴 수 있습니다. 컴퓨터가 절전 모드로 들어가지 않도록 하고, 백업 프로그램이 연 Chrome 창과 검은색 창을 닫지 마세요.

일부 곡이 실패해도 프로그램은 가능한 경우 다음 곡으로 넘어갑니다. 나중에 같은 파일을 다시 실행하면 실패했거나 빠진 파일을 다시 확인합니다.

## 8단계: 받은 파일 확인하기

1. `sunofile-main` 프로그램 폴더를 엽니다.
2. 그 안의 `downloads` 폴더를 엽니다.
3. Workspace 이름으로 된 폴더를 엽니다.

파일은 다음과 같이 저장됩니다.

```text
downloads/
├─ account-download-history.json
└─ 작곡용/
   ├─ 001 - 달빛 아래 너를 그려.wav
   ├─ 001 - 달빛 아래 너를 그려.mp3
   ├─ 001 - 달빛 아래 너를 그려 - lyrics.txt
   ├─ 001 - 달빛 아래 너를 그려 - prompt.txt
   └─ 001 - 달빛 아래 너를 그려 - metadata.json
```

- `.wav`: 고음질 음악 파일
- `.mp3`: 일반 음악 재생용 파일
- `lyrics.txt`: 가사
- `prompt.txt`: 생성 프롬프트와 스타일
- `metadata.json`: 곡 ID와 각종 곡 정보
- `account-download-history.json`: 어떤 곡을 받았는지 기록하는 파일

`account-download-history.json`은 이어받기에 필요하므로 특별한 이유가 없다면 삭제하지 마세요.

---

## 중간에 멈추거나 오류가 난 경우

걱정하지 말고 `Suno_전체_백업_실행.cmd`를 다시 두 번 클릭하세요.

프로그램은 다음 내용을 확인합니다.

- 정상 WAV 파일이 이미 있는지
- 정상 MP3 파일이 이미 있는지
- 가사, 프롬프트, 메타데이터 파일이 비어 있지 않은지

정상 파일은 다시 받지 않고 빠졌거나 손상된 파일만 보충합니다.

### 내가 직접 중단하려면

검은색 창을 한 번 클릭한 뒤 키보드의 `Ctrl` 키를 누른 상태에서 `C` 키를 누릅니다. 현재 처리 기록을 저장하고 종료한다는 메시지가 나오면 잠시 기다리세요.

창의 오른쪽 위 `X`를 눌러 강제로 닫는 것보다 `Ctrl+C`로 중단하는 것이 안전합니다.

### Chrome 창을 실수로 닫은 경우

프로그램이 자동으로 새 탭이나 Chrome을 열고 중단된 곡부터 다시 시도합니다. 계속 복구하지 못하면 프로그램을 완전히 닫은 뒤 `Suno_전체_백업_실행.cmd`를 다시 실행하세요.

## 자주 발생하는 문제

### `Install Node.js 20 or newer`라고 표시됩니다

Node.js가 설치되어 있지 않거나 설치 직후 Windows가 아직 인식하지 못한 상태입니다.

1. 이 문서의 **Node.js 설치하기**를 따라 설치합니다.
2. 열려 있는 프로그램 폴더와 검은색 창을 모두 닫습니다.
3. 다시 실행합니다.
4. 계속 같은 메시지가 나오면 Windows를 재부팅합니다.

### `Google Chrome was not found`라고 표시됩니다

[Google Chrome](https://www.google.com/chrome/)을 설치한 후 다시 실행하세요. 다른 브라우저만 설치되어 있어도 이 프로그램은 Chrome을 찾습니다.

### `YOUR_WORKSPACE_ID를 바꾸세요`라고 표시됩니다

`config.json`에 본인의 Workspace 주소가 아직 입력되지 않은 상태입니다. 이 문서의 **4단계**와 **5단계**를 다시 확인하세요.

### `config.json` 오류가 표시됩니다

메모장으로 수정하면서 큰따옴표나 쉼표가 지워졌을 수 있습니다.

1. 현재 `config.json`을 다른 이름으로 바꾸거나 삭제합니다.
2. `Suno_전체_백업_실행.cmd`를 다시 실행하여 새 파일을 만듭니다.
3. Workspace 주소 부분만 조심해서 다시 바꿉니다.

### 로그인했는데 다시 로그인하라고 합니다

1. 백업용 Chrome 창을 모두 닫습니다.
2. `Suno_로그인_준비.cmd`를 다시 실행합니다.
3. Suno의 Library가 보일 때까지 로그인합니다.
4. 전용 Chrome 창을 완전히 닫습니다.
5. 전체 백업을 다시 실행합니다.

### MP3는 받았는데 WAV가 실패합니다

WAV 다운로드는 해당 기능을 제공하는 Suno 구독이 필요할 수 있습니다. 구독 상태와 Suno 사이트에서 해당 곡을 직접 WAV로 받을 수 있는지 확인하세요. Suno에서 WAV를 준비하는 시간이 오래 걸리면 다음 실행에서 다시 성공할 수도 있습니다.

### 일부 곡만 실패합니다

인터넷 상태나 Suno 서버 상태 때문에 일시적으로 실패할 수 있습니다. 프로그램을 다시 실행하면 누락된 파일을 재시도합니다. 자세한 오류 화면과 진단 정보는 프로그램 폴더의 `logs` 폴더에 저장됩니다.

### 검은색 창의 한글이 깨져 보입니다

최신 Windows에서는 보통 정상 표시됩니다. 한글이 깨져도 프로그램 동작에는 영향이 없을 수 있습니다. 폴더 경로가 너무 길거나 특수문자가 많다면 `sunofile-main` 폴더를 바탕 화면이나 `C:\sunofile`처럼 짧은 위치로 옮긴 뒤 다시 시도하세요.

## ChatGPT 또는 Codex에게 설치를 부탁하는 방법

사용자의 컴퓨터 파일과 터미널에 접근할 수 있는 ChatGPT 데스크톱 앱의 Codex 또는 Codex CLI를 사용한다면 설치 도움을 받을 수 있습니다. 일반 웹 채팅은 설명은 해줄 수 있지만 사용자의 컴퓨터에 직접 설치하지는 못할 수 있습니다.

다음 문장을 복사해서 요청하세요.

> Windows PC에 https://github.com/rubyonsoft/sunofile 프로젝트를 설치하고 실행해줘. README를 먼저 읽고 Node.js와 Chrome 설치 여부를 확인해줘. 안전한 폴더에 설치하고, config.json의 Suno Workspace 주소가 필요한 단계와 Chrome 로그인 단계에서는 내가 직접 할 수 있도록 멈춰서 알려줘. 기존 음악은 삭제하지 말고, 먼저 설정과 로그인을 확인한 다음 전체 백업을 실행해줘. 오류가 나면 원인을 확인하고 이어서 실행해줘.

로그인과 Windows 관리자 권한 확인 창은 사용자가 직접 승인해야 할 수 있습니다. ChatGPT나 다른 사람에게 Suno 비밀번호를 보내지 마세요.

## 개인정보와 음악 파일 보호

다음 항목은 Git에 올라가지 않도록 설정되어 있습니다.

- 개인 Workspace 주소가 들어 있는 `config.json`
- 로그인 정보가 들어 있을 수 있는 `.browser-profile` 폴더
- `downloads` 폴더의 음악, 가사, 프롬프트 및 기록
- `logs` 폴더의 오류 화면과 진단 정보
- 모든 WAV, MP3, M4A, FLAC, AAC, OGG 음악 파일

프로그램 폴더 전체를 다른 사람에게 보내면 Git 제외 설정과 관계없이 개인정보나 음악 파일까지 함께 전달될 수 있습니다. 다른 사람과 공유할 때는 프로그램 폴더를 압축하지 말고 이 GitHub 주소만 알려 주세요.

## 고급 사용자용 명령어

이 부분은 초보자가 따라 할 필요가 없습니다.

```powershell
git clone https://github.com/rubyonsoft/sunofile.git
cd sunofile
Copy-Item config.example.json config.json
npm install
npm start
```

`npm start`는 기본적으로 MP3와 WAV를 모두 다운로드합니다. 형식을 직접 지정할 수도 있습니다.

```powershell
# MP3만 다운로드
npm start -- --format mp3

# WAV만 다운로드
npm start -- --format wav

# MP3와 WAV 모두 다운로드
npm start -- --format both
```

한 곡만 시험합니다.

```powershell
npm start -- --format both --limit 1
```

파일을 다운로드하지 않고 곡 목록만 확인합니다.

```powershell
npm run scan
```

목록 확인을 10곡으로 제한합니다.

```powershell
npm run scan -- --limit 10
```

테스트를 실행합니다.

```powershell
npm test
```

## 주요 설정값

`config.json`에는 다음 값이 있습니다. 초보자는 `workspaceDiscoveryUrl` 이외의 값을 바꾸지 않는 것이 좋습니다.

- `workspaceDiscoveryUrl`: 계정에 속한 Workspace 주소 하나
- `includeArchivedWorkspaces`: `true`이면 보관된 Workspace도 포함
- `downloadDirectory`: 결과 저장 폴더
- `delayBetweenDownloadsMs`: 곡 사이 대기 시간
- `downloadTimeoutMs`: WAV 준비와 파일 다운로드 제한 시간
- `downloadRetryCount`: 곡별 재시도 횟수
- `browserRestartCount`: Chrome 종료 시 자동 복구 횟수

요청 간격을 너무 짧게 줄이면 Suno 서비스에 부담을 줄 수 있으므로 기본값 사용을 권장합니다.
